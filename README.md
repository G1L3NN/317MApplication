# Clock by Glenn

## Entstehungsprozess

Die Idee für dieses Projekt kam mir, als ich auf Reddit ein Spreadsheet gefunden habe, in dem eine ASCII-Clock als Vorschlag erwähnt wurde.
Diese Idee wollte ich jedoch noch weiter verfeinern und habe deshalb eine Uhr mit einigen Spezial-Features entwickelt.

Ich wünsche viel Spaß beim Benutzen meiner Uhr.
Zum Starten gib /help im Terminal ein.
